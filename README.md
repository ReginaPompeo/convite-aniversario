# Convite de aniversário — Country 🤎

Site estático, pronto para Netlify.

## Antes de publicar
Abra `script.js` e troque:
`const WHATSAPP = "SEUNUMEROAQUI";`

por seu número com DDI + DDD, sem espaços, parênteses ou símbolos.
Exemplo: `5511999999999`

## Publicar no Netlify
Você pode arrastar a pasta inteira para o Netlify, ou conectar um repositório Git.

Não precisa de React, Next ou build: é HTML + CSS + JavaScript puro.
